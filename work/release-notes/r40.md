## Deyva v0.8.98-r40

Android 胶片模拟冲洗应用。光谱物理引擎移植自 [SpektraLab](https://github.com/JamesQiu2005/SpektraLab)，胶片过程模型与实测色彩数据来自 [spektrafilm](https://github.com/andreavolpato/spektrafilm)。

### 导出完整性

- 大尺寸图像导出不再出现缺行、横带或半幅空白。
- GPU 拷贝改为分块提交，逐块校验；负片缓存增加首行、中间行、末行一致性检查。
- 导出前释放空闲显存；渲染后校验全零行，必要时重渲并以逐行合并补齐，确保输出完整。

### 导出分辨率

- 导出上限改为按设备 GPU 实测能力判定，替代原有固定阈值。
- 按所选档位直接渲染，不再先渲染全幅再缩放。

### RAW 导入

- 支持 Sony ARW 6.0 Compressed / Compressed HQ（A7 V）。
- 新增「导入文件」入口，可直接读取相册未索引的 RAW 文件。
- 解码失败不再清空胶片条，保留上一张并输出失败原因。
- 自动裁除光学黑遮罩行列，消除画面边缘黑边。

### 其他

- 修正导出尺寸显示错误（此前显示为「1 × 0 · 0.0 MP」）。
- 负片反差控件回归主界面。

### 已知限制

- 相机原生全分辨率受 GPU 单块缓冲上限约束，设备实际可用上限由引擎实测上报。
- ARW6 解码器移植自 LibRaw 0.23 未发布分支，尚未以 A7 V 压缩样本做逐像素比对。
